# 2024 Taiwan Family Income and Expenditure Survey (TFIES) Analysis

## 作業概述
本作業為社會統計分析實作，主要運用 R 語言處理「2024 年家庭收支調查 (TFIES)」之 SPSS 原始資料 (`inc113.sav`)。作業目標為計算台灣家庭與個人層級之所得總額及可支配所得，並透過加權處理還原母體特徵，最後進行資料統計圖分析。

## 分析指標
利用程式碼處理並產出以下統計指標：
*   **總體估計**：家庭總戶數、每戶平均人數。
*   **平均數分析**：
    *   每戶 / 每人所得總額
    *   每戶 / 每人可支配所得平均數
*   **中位數分析**：
    *   每戶可支配所得中位數
    *   每人可支配所得中位數

## 依賴套件
執行本作業需安裝並載入以下 R 套件：
*   `dplyr`: 資料清理與操作
*   `haven`: 讀取 SPSS `.sav` 格式資料
*   `labelled`: 處理標籤化資料
*   `ggplot2`: 資料視覺化

## 核心資料處理邏輯
1.  **資料預處理**：針對變數 `itm600` 進行缺失值 (NA) 填補，並計算核心變數 `income` (可支配所得 = `itm400` - `itm600`)。
2.  **加權計算**：使用調查權數變數 `a20` (戶數權重) 與 `a8` (戶內人數)，進行加權平均與總和計算。
3.  **中位數推估**：透過累積人口數 (`CumPersons`) 與累積戶數 (`CumHouseholds`)，精確定位可支配所得之中位數落點。
4.  **視覺化**：排除極端值 (Top 1%) 後，繪製可支配所得分配之直方圖。
